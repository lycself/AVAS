更新下载现在显示进度条、下载量、百分比和平均速度，校验与解压分别显示状态，刷新页面也可恢复进度。

改进 Windows 更新时的文件占用处理：短暂占用会重试，持续占用或权限不足时明确提示受影响文件；通过临时文件替换避免复制失败损坏旧文件，保留失败恢复与备份。

更新器确认启动并创建日志后才关闭程序；补充启动日志、日志备用位置及结果中的错误详情，日志不可用时不再只提示查看日志。旧版更新器无法升级时，需手动安装新版安装包一次。

安装包、便携版、源码 ZIP 和 Git 版统一增加独立更新状态窗口，明确说明完成后自动重启。更新期间重复打开程序会提示等待并阻止新实例启动，避免再次打开的程序占用待更新文件；更新窗口保留到重启后的主窗口显示，异常退出的遗留状态不会永久锁住启动。
