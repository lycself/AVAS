# 发布变更记录

提交前，由 AI 或开发者新增一个有意义名称的 `.md` 文件，例如 `20260920-windows-installer.md`。
写 1–6 条用户能理解的变化，使用普通文字和 `•`，不直接复制提交标题，不需要用户每次提醒。
没有用户可感知变化时也明确写出内部维护的范围，不能用通用空话代替说明。

已提交的条目保留且不修改；同一次尚未提交的修改可以更新自己的条目。补充或纠正历史说明请新增条目。
误改后的修复只允许按 Git blob 精确恢复到该路径首次提交的原文，补充内容移入新增条目；修复提交仍须包含新的非空说明。其他改写或删除继续拒绝。
CI 检查本次提交范围有新增且非空的条目，不能自动判断文案质量，作者需审核。

发布时从 `avas-latest/update.json` 读取上次成功发布的提交，汇总此后新增条目。
失败构建不会消费条目；重试已发布提交不会改写其包或说明。首次发布汇总所有条目。
只做整理，不调用模型，不读取提交标题生成文案，不自动提交回仓库。

生成文件为 `dist/updates/docs/update-notes.md`，也放入官方源码包的 `docs/update-notes.md`。
`update.json` 和 Release 的“本次更新”使用同一份说明；下载说明只附在 Release 正文中。
Windows 首次安装用 `AVAS-版本-setup.exe`，自动更新仍使用 `avas-windows.zip`。
