## 2026-09-19  前后端分离的通信层、浏览器模式

- 界面前后端只通过 HTTP 通信（`POST /api/rpc`、WebSocket `/api/events`、`/blob/`），桌面窗口和浏览器走同一条通路，
  pywebview 只负责窗口和原生文件对话框（不再使用 js_api 和 `evaluate_js` 推送事件）。服务器为 Starlette + uvicorn。
- 新增 **`avas serve`**：不开窗口，在浏览器里使用同一个界面（`--open` 自动打开，`--host` / `--port` 指定地址）。
  浏览器里没有原生对话框，改用页面自带的文件夹 / 文件选择器；「打开文件夹」显示带下载按钮的目录，「打开文件」和导出图直接下载；
  菜单没有「退出」。这是将来部署到服务器的第一步，用户管理、工作区隔离尚未实现，`--host 0.0.0.0` 仅限可信网络。
- 通信加**访问令牌**：启动时随机生成并写进页面地址，每个请求都要携带；此前本机任意网页都能调用 RPC 读写文件。
- `python -m avas.gui.devserver` 保留为 `avas serve --token dev --settings .dev-gui.json` 的别名，`?devrpc` 参数不再需要。
- 新增 `tests/test_server.py`（真实 uvicorn：令牌、RPC、blob、WebSocket 事件、下载、静态文件、关闭）。

## 2026-09-17  v2.0.0  暂停模拟、分段模拟、3D 视图导航

- 运行可以**暂停 / 继续**：挂起整个模拟进程树，继续后从原处接着计算（内存中暂停，关闭软件等于停止）。顶栏按钮、
  运行页主按钮和 F5 依次为 运行 → 暂停 → 继续；暂停时进度条和状态为琥珀色，已用时间不计暂停时长，恢复后几秒内
  用进度速率估算剩余时间（内核自己的估算仍包含暂停）。
- AI 助手在沙盒中进行的参数扫描 / 优化也显示在运行页、顶栏和状态栏（第几次模拟），可暂停、继续、停止；
  期间不能启动普通运行，也不能切换项目。
- **分段模拟**（AI 工具 `run_segment`）：按 section / 标题、起止元件或 z 范围只模拟 lattice 的一段，结果写入
  `Segments/<名称>_<时间>/`，不改动项目文件和 OutputFile；确认卡片中选择入口束流：beam.txt（从起点开始时）、
  上次全线模拟在入口处的粒子文件、先模拟上游、由入口处 Twiss 参数生成（近似）。叠加场块和周期不会被切开；
  输出面裁剪到段内（内核拒绝超出末端或距末端过近的输出面）。
- 分段入口束流新增「接续已有分段结果的出口束流」：已完成的分段运行若正好结束在本段入口，直接用其段末粒子文件，
  无需再模拟上游（CAFe 的 CM4：212 s，先模拟上游约 15 min；出口能量偏差 4e-6，尺寸与发射度约 0.1 %）。每次分段
  运行记录上游 lattice 与 beam.txt / input.txt 的指纹，上游改动后旧结果不再可选；时间零点取上一段参考粒子实际到达
  段末的时刻（参考粒子由入口束流平均能量定义，经过两个低温模块后与设计时刻相差约 0.4° RF 相位）。
- 分段不从起点开始时，先做单粒子参考运行，段内射频场改写为 V3 = 2、按原绝对时序换算相位
  （φ = φRF − 360°·f·(t_in − T)）。与全线模拟对比：用粒子文件入口时出口能量偏差 2e-5、rms 尺寸与发射度偏差约 0.3 %；
  Twiss 入口能量 2e-4、尺寸约 4 %、发射度约 11 %。
- 结果页新增「结果」来源选择：全线（OutputFile）与各次分段模拟；分段结果注明 z 从段入口起算；运行页「查看结果」
  直接打开对应结果。结果文件夹的输入目录按其 `avas_run.json` 确定。
- 3D 视图：右键或中键拖动平移，工具栏「平移模式」让左键平移；触控板双指滑动平移、双指捏合缩放（自动识别鼠标 / 触控板，
  可在 ⓘ 菜单中指定）；←/→、Home/End 沿束线移动；视图下方新增位置条（元件分布、可见范围，单击 / 拖动跳转，
  双击选中元件）。标签可点击选中、双击聚焦；位置重叠的叠加元件合并为一个标签，每个名称可单独点击。
